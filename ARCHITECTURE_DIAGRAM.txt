================================================================================
                            DATA FLOW EXAMPLE
================================================================================

Let's trace what happens when you do a push-up:

1️⃣  USER DOES PUSH-UP
    ↓
    Camera captures video frame
    ↓

2️⃣  MEDIAPIPE DETECTS POSE (Frontend)
    ↓
    33 body landmarks identified
    - Shoulders, elbows, wrists, hips, etc.
    ↓

3️⃣  EXERCISE ANALYZER EVALUATES FORM (Frontend)
    ↓
    PushUpAnalyzer.analyze(landmarks)
    - Calculates elbow angle (should be 90°)
    - Checks body alignment (straight line)
    - Detects if hips are sagging
    - Generates feedback: "Good form! Keep core engaged."
    - Scores: 92/100
    ↓

4️⃣  FRONTEND DISPLAYS FEEDBACK
    ↓
    - Green skeleton overlay
    - Form score: 92% (blue indicator)
    - Message: "Good form!"
    - Rep count increments: 1 → 2
    ↓

5️⃣  WHEN WORKOUT ENDS, FRONTEND SENDS TO BACKEND
    ↓
    API.workout.recordPerformance({
      session_id: "abc123",
      exercise_id: "push-ups",
      reps_completed: 15,
      average_form_score: 92.5,
      duration_seconds: 120
    })
    ↓

6️⃣  SUPABASE CLIENT SENDS HTTPS REQUEST
    ↓
    POST https://cknhitafyibctnkuezjc.supabase.co/rest/v1/exercise_performances
    Headers: { Authorization: "Bearer <token>" }
    Body: { ... performance data ... }
    ↓

7️⃣  BACKEND SAVES TO DATABASE
    ↓
    INSERT INTO exercise_performances (...)
    VALUES (...)
    ↓

8️⃣  DATABASE TRIGGERS FIRE AUTOMATICALLY
    ↓
    • Award 50 XP → User now has 1,250 XP (Level 13)
    • Update daily_stats → workouts_count += 1
    • Check achievements → "100 Push-ups" unlocked! 🏆
    • Update leaderboard → User moved to rank #42
    ↓

9️⃣  FRONTEND QUERIES UPDATED DATA
    ↓
    API.progress.getStats()
    ↓
    Returns: { totalWorkouts: 37, xp: 1250, level: 13, ... }
    ↓

🔟 USER SEES UPDATED STATS
    ✓ Workout saved!
    ✓ 50 XP earned! (Level 13)
    ✓ Achievement unlocked: "100 Push-ups"
    ✓ New rank: #42 on leaderboard
