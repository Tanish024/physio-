# AI-FIT-Hack 🏋️‍♂️

AI-powered fitness guide application with real-time pose detection, personalized workout plans, and progress tracking.

## 🚀 Features

- **AI Pose Detection**: Real-time exercise form analysis using TensorFlow.js and MediaPipe  
- **Personalized Workouts**: Custom workout plans based on fitness goals  
- **Progress Tracking**: Track your fitness journey with detailed analytics  
- **Location-based Gyms**: Find nearby gyms using Google Maps integration  
- **User Authentication**: Secure login and profile management with Supabase  
- **Email Notifications**: Automated welcome emails via EmailJS  
- **Responsive Design**: Beautiful UI with shadcn/ui and Tailwind CSS  

## 🛠️ Tech Stack

- **Frontend**: React 18 + TypeScript  
- **Build Tool**: Vite  
- **Styling**: Tailwind CSS + shadcn/ui components  
- **AI/ML**: TensorFlow.js + MediaPipe for pose detection  
- **Backend**: Supabase (Authentication & Database)  
- **Maps**: Google Maps API  
- **Email**: EmailJS  
- **State Management**: TanStack Query  
- **Animations**: Framer Motion  

## 📋 Prerequisites

- Node.js (v18 or higher)  
- npm or yarn  
- Git
